2. Project Overview

The Musanze Harvest Intelligence Service is a reproducible machine learning prototype designed to support a potato cooperative in Musanze, Rwanda. It processes farm records and provides harvest-yield estimates, high-production-risk predictions, and farm clusters.

The system implements three machine learning tasks:

Regression: Estimates potato harvest yield in tons.
Classification: Predicts whether a farm is at high production risk.
Clustering: Groups farms with similar input characteristics.

The project also provides a command-line prediction tool and a FastAPI service for programmatic inference.
